# video2score 视频转谱

把 B 站等网站上的动态谱视频（贝斯、吉他的五线谱 + TAB）转成：

- 截图谱 PDF：视频截图拼成的干净乐谱；
- MusicXML、Guitar Pro 文件（.gp / .gpx / .gp5），可以导入 Guitar Pro 8；
- 排版 PDF：按识别结果重新排版的谱。

不用安装 Python、Node，解压就能用。

## 打开

- **Windows**：双击 `video2score.exe`。会弹出一个黑色窗口（显示运行地址和日志），并自动在浏览器里打开操作页面。用完关掉黑色窗口，或在页面上点"退出"。
- **macOS**：双击 `video2score.app`，浏览器里会自动打开操作页面。用完在页面上点"退出"。
  - 第一次打开时系统会提示"无法验证开发者"：在访达里**右键 → 打开**，再点"打开"。
  - 如果页面顶上提示"程序放在了临时的只读位置运行"，先把整个 `video2score` 文件夹挪到别的位置（比如"应用程序"或"文稿"）再打开；或者照提示在终端运行那一行命令。

如果浏览器没有自动打开，就复制黑色窗口里显示的地址（`http://127.0.0.1:…`）到浏览器。

## 使用

1. 粘贴视频链接（B 站链接、BV 号、YouTube 链接或其他视频网站链接），或者把视频文件拖进页面。拖入本地视频时可以另填原视频链接，这样能补上曲名、原唱，页脚印上出处。
2. 勾选要导出的格式，点"开始转谱"。进度显示在"进行中"。一首歌通常要一到几分钟。
3. 做好的谱在"我的谱"里：点文件名下载或打开；"看要核对的小节"列出识别时没把握的小节（带截图），建议在 Guitar Pro 里对照视频看一下。
4. 右上角"B 站登录"用手机扫码登录后，能下载更清晰的视频，识别更准。

YouTube 视频要能正常访问 YouTube：平时用代理的话，打开系统代理后再转。

## 文件存在哪里

所有东西都在 `video2score` 这个文件夹里，不往别处写：

```text
video2score/
  data/jobs/      每首谱一个文件夹
  data/uploads/   拖进来的视频
  data/trash/     页面上删除的谱（需要时可以拿回来）
  data/config/    B 站登录信息
  data/logs/      运行日志（出问题时可以发给作者）
```

- **卸载**：直接删掉整个 `video2score` 文件夹。
- **升级**：解压新版本后，把旧版本的 `data` 文件夹拷进去。
